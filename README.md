# Musicapp
🎵 Music App
A simple and elegant music streaming website that fetches music from a local folder and displays it on the site. The app provides a smooth user experience with an enhanced frontend, allowing users to browse, play, and control their favorite tracks effortlessly.

🚀 Features
🎼 Fetches music from a local folder
🎵 Play, pause, skip tracks with an intuitive UI
🎨 Enhanced frontend with a user-friendly design
🔍 Track listing & searching for easy navigation
📂 Dynamic music loading without manual updates
